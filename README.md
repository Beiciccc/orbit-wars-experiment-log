# Orbit Wars Experiment Log

Public notes and result summaries for the Kaggle Orbit Wars simulation competition.

This repository is intentionally limited to:

- project overview
- experiment summaries
- public leaderboard snapshots
- submission score history
- notes from public competition discussions and public code review

It does not include implementation code, private configuration, infrastructure details, or unpublished competition assets.
